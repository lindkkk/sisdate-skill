# sisdate-skill

一个面向 Claude Code / Codex / Claude Desktop 等智能体代理的**姐弟恋约会活动匹配** Skill。

**核心场景**：跨年龄组约会活动（女性年长 5+ 岁），同城匹配，通过 agent 对话发布或浏览活动、互发站内短信。

> 当前状态：📋 规划完成，代码开发启动中（MVP 阶段 4 开工）。
> 仓库暂为占位骨架，接口契约随 server 仓同步演进。

## 特性（MVP 目标）

- 🎯 **完全匿名**：无用户名 / 密码 / 邮箱，Token 即身份
- 🪶 **零感知注册**：首次使用 30 秒填一个下拉表单即可
- 📍 **硬约束匹配**：同城 + 异性 + 女性年龄 ≥ 男性年龄 + 5 岁
- 💬 **站内异步通信**：用 8 位公开 ID 定向发消息
- 📅 **每日精选**：每天最多浏览 2 条符合条件的活动
- 🔄 **跨设备迁移**：粘贴 Token 即可在新设备继续

## 典型对话示例

- "我想发一个周六下午看展的活动" → skill 推送浏览器表单链接
- "有什么活动" → skill 返回当日一条匹配活动
- "给 ABCDE234 发消息：你好" → skill 发送站内短信
- "我有新消息吗" → skill 返回收件箱摘要
